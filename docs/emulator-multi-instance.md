# 模拟器 / 虚拟机多窗口的 IP 分配思路

多开环境的网络配置难点不在客户端本身，而在「一个窗口对应一个出口」的映射关系。下面是按顺序整理的做法，适用于 MuMu、雷电、蓝叠以及常见虚拟机环境。

## 1. 先算窗口数与套餐是否匹配

- 统计同时在线窗口数，而不是安装实例数。
- 套餐窗口数按「同时在线」计算，超出部分会被挤出。
- 需要留出 1–2 个窗口的余量给调试。

窗口与套餐的对应关系见 [无虑包机多开设置](https://www.wyouip.com/products/wulv-baoji)。

## 2. 客户端放在宿主机，不要装进模拟器

- 装在 Windows 宿主机上，由它统一分配节点。
- 模拟器内不需要再装代理软件，避免双层代理导致延迟叠加。
- 用「进程代理」模式时，把模拟器进程逐个勾选，未勾选的进程仍走本机网络。

## 3. 每个窗口绑定独立节点

1. 在客户端窗口列表里找到对应的模拟器实例。
2. 为该实例选择节点，不要沿用上一个窗口的节点。
3. 在同一模拟器里登录多个账号时，账号与窗口要固定对应，避免今天 A 窗口明天 B 窗口。

## 4. 换 IP 的时机

- 定时切换：在客户端设置里给出间隔，切换期间不要重启模拟器。
- 手动切换：先关闭该窗口内的业务进程，再切换节点，最后重新打开。
- 大面积掉线先查 [公告中心](https://www.wyouip.com/notices) 的线路维护，不要先改配置。

## 5. 常见异常处理

| 现象 | 优先检查 |
| --- | --- |
| 模拟器内能上网但出口 IP 未变 | 进程是否被勾选、客户端是否以管理员运行 |
| 部分窗口无法联网 | 该窗口是否分配到已下架的节点 |
| 延迟突然升高 | 节点所属地区是否在维护、宿主带宽是否跑满 |
| 登录后很快掉线 | 是否多个窗口共用同一节点 |

更完整的排查顺序见 [无忧IP常见问题](https://www.wyouip.com/faq) 与 [使用教程](https://www.wyouip.com/tutorials)。
