## 三类客户端怎么选

| 使用场景 | 建议客户端 | 说明 |
| --- | --- | --- |
| Windows 电脑单机、浏览器或工具走代理 | 无忧IP 电脑客户端 | 支持静态与动态 IP，可按窗口或进程分配节点 |

## Windows 上手五步

1. 在下载中心取电脑客户端安装包，核对版本号与系统要求。
2. 安装后使用购买的账号登录，首次登录建议先看节点列表的延迟数值。
3. 按用途选节点：需要固定出口选静态，需要按周期更换选动态。
4. 在客户端里把节点分配到「全局」或指定的窗口/进程，避免整机流量走代理。
5. 打开浏览器或目标工具，用 IP 查询页确认出口 IP 与所选节点一致。

连接不上时按顺序排查：账号是否到期 → 节点是否在维护 → 本机防火墙是否拦截 → 客户端版本是否过旧。完整清单见 [无忧IP常见问题](https://www.wyouip.com/faq)。

## 模拟器多窗口要点

- 先确认模拟器实例数量，再按实例分配窗口，不要超过套餐窗口数。
- 每个实例单独绑定节点，避免多个窗口共用同一出口。
- 需要定时更换 IP 时开启自动切换，切换期间不要重启模拟器。
- 出现大面积掉线先看 [公告中心](https://www.wyouip.com/notices) 是否有线路维护。
